# Data folder structure

## raw
Original source data files. Do not edit files manually.

## interim
Temporary files created during cleaning or reshaping.

## processed
Final tidy datasets ready for analysis and modelling.
These should be generated from scripts, not edited by hand.

housing_quarterly.csv = quarterly NI HPI dataset
housing_annual.csv = annual aggregated housing dataset for easier integration
